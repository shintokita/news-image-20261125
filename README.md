# The World in One Day — 25 November 2026

A make.fun entry for **news-image-20261125** ("Sum up 25 November's world news in one image").

The image is a one-page editorial sheet for Wednesday 25 November 2026, drawn
programmatically in a flat newspaper style. Five stories, five regions:

- **Europe – War:** Ukraine's sea drones sink a Russian warship off Libya
- **Middle East:** Houthi attack hits a Riyadh skyscraper again, 11 hurt
- **America – Politics:** Democrats clinch their biggest House majority in decades
- **America – Tech:** Trump backs Nvidia's chief in the chip export fight
- **Asia – Space:** Shenzhou-24 lifts off with Pakistan's first astronaut aboard

`main.ts` (Node 22, standard library only) copies the bundled `entry.png` to the
grader's output directory. Run it locally with:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
